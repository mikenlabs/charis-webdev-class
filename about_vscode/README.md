# About VS Code - Teaching Project

A simple project to help students learn to navigate VS Code.

## Project Structure
- `index.html` - Main page with VS Code info
- `style.css` - Basic styling
- `script.js` - Simple interactivity

## Tips for Students
1. Use the Explorer panel to navigate files
2. Right-click to open files in a new tab
3. Use Ctrl+P to quickly find and open files
4. Click the split arrow to view files side by side
